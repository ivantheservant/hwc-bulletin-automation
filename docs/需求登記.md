## E. 第一輪自測之後新增

| 編號 | 需求 | 狀態 |
|---|---|---|
| R-028 | 星期一觸發器**真環境**驗證：在真的 Apps Script 上，由觸發器自己跑一次 `weeklyBulletinSendTrigger_()`，確認選中的主日、寄出的封數、`SendLog` 三者對得上 | 未開始 |
| R-029 | `Recipients` 填齊 CC（堂委）、DB（執事）、IT 三組收件人——目前只有 ADMIN 一組，R-004 的勾選功能等於只有一個選項可以勾 | 未開始 |

**R-028 為什麼要另立一條**：自測機 S18 **沒有**真的呼叫
`weeklyBulletinSendTrigger_()`——那一支會順手替真實季度建立季度填寫表，
違反沙盒規則。所以 S18 只驗「算出來的目標主日對不對」，不驗「觸發器整條
路徑跑不跑得通」。那一段仍然是人手驗證，不可以因為 S18 綠了就當驗過。

**R-029 為什麼是需求不是設定**：`Recipients` 只有 ADMIN 一組的話，
「發佈與寄出」的收件對象勾選（R-004）表面上做好了，實際上寄出去只會到
幹事自己一個人手上。這件事**不會有任何錯誤訊息**——寄成功、`SendLog`
綠色、封數 1。所以「完成度自我檢測」把它報成 🟡 而不是 🟢。
