# Word 範本製作指引

這份文件教你怎樣由**現行的週報 Word 檔**做出一個**範本**，讓系統每星期
自動把當週的內容填進去。

全部操作都在 Word 內完成，不需要懂程式。

佔位符的完整清單見 [佔位符對照表.md](佔位符對照表.md)。

---

## 先講清楚：系統做什麼、不做什麼

| | |
|---|---|
| ✅ 系統會做 | 把範本上的佔位符換成當週的內容；表格該有幾多列就複製幾多列；沒有內容的列自動刪掉 |
| ❌ 系統**不會**做 | 改任何格式、字型、字級、行距、邊界、欄寬、圖片位置、文字方塊、圓角矩形 |

**版面 100% 由你的範本決定。** 系統從來不重畫版面，只換字——所以範本
排成什麼樣，印出來就是什麼樣。

💡 這也是為什麼系統交付的是 `.docx` 而不是 PDF：轉 PDF 一定要先經過
Google 文件格式，那一步會丟失文字方塊與圓角矩形、破壞 A5 兩頁併印與三欄
排版、把港式字型換走——等於把版面重做一次。

---

## 需要做幾多個範本

三個，對應三種主日：

| 範本 | 什麼時候用 | Config 設定鍵 |
|---|---|---|
| 平常主日 | 大部分主日（包括聖餐主日、祈禱會週） | `TEMPLATE_FILE_ID_NORMAL` |
| 浸禮三堂聯合崇拜 | 浸禮主日 | `TEMPLATE_FILE_ID_COMBINED_BAPTISM` |
| 堂慶三堂聯合崇拜 | 堂慶主日 | `TEMPLATE_FILE_ID_ANNIVERSARY` |

💡 可以先只做「平常主日」一個，另外兩個之後再補。範本 ID 留空時，系統會
明確講「尚未設定 Word 範本」，不會靜靜出錯。

---

## 步驟

### 第 1 步：另存新檔

揀一份**最近、最典型**的週報（平常主日那種），另存為
`平常主日範本.docx` 之類的名。

⚠️ **一定要另存新檔**，不要直接改原檔。

### 第 2 步：逐格換成佔位符

由封面開始，逐格把「每週都會變」的字換成對應的佔位符。

**例：**

| 原本 | 改成 |
|---|---|
| `2027 年 11 月 07 日` | `{{SERVICE_DATE_COVER}}` |
| `因信稱義` | `{{SERMON_TITLE}}` |
| `羅馬書 3:21-26` | `{{SCRIPTURE_REF}}` |
| `120`（英語堂崇拜人數） | `{{ATT_ENG_WORSHIP}}` |

**不要動的東西：**

- 固定不變的字（「崇拜程序」「主席」「講員」這些欄目標題）
- 教會標誌、圖片、頁碼
- 任何格式

#### ⚠️ 打佔位符的正確方式

**選取原本那串字 → 直接打新的佔位符**，一口氣打完。

**不要**：
- 打一半停下來去做別的事再回來接
- 用複製貼上拼湊出半截
- 在已經打好的佔位符中間再插字

原因見下面「常見錯誤 1」。

### 第 3 步：處理會變長變短的表格

家事報告、代禱事項、事奉名單、團契聚會、財政報告——這些**行數每週不同**。

做法：**只留一列**，其餘刪掉，然後在那一列加標記。

**例：家事報告表本來有 5 列**

刪到只剩 1 列，然後：

| 第一格 | 第二格 |
|---|---|
| `{{#EACH:ANNOUNCEMENT}}{{ANNOUNCEMENT.NO}}` | `{{ANNOUNCEMENT.TEXT}}` |

系統會按當週實際的則數，把那一列複製成 3 列、8 列……一則都沒有就整列刪掉。

⚠️ **`{{#EACH:}}` 要放在那一列第一格的最前面。**

七個清單的名稱與欄位見 [佔位符對照表.md](佔位符對照表.md) 的「第二類」。

### 第 4 步：崇拜程序表要留**兩列**

程序表比較特別，因為有兩種列：

- **一般列**（三格）：`序樂｜安靜｜眾 立`
- **全寬列**（一格跨欄置中，沒有立坐）：`祈禱會`

而且兩者是**交錯**出現的（「祈禱會」排在「家事報告」之後），所以要留兩列：

| | |
|---|---|
| **第一列**（保持三格） | 第一格：`{{#EACH:PROGRAM}}{{PROGRAM.ITEM}}`<br>第二格：`{{PROGRAM.CONTENT}}`<br>第三格：`{{PROGRAM.POSTURE}}` |
| **第二列**（合併成一格跨三欄，置中） | `{{#EACH:PROGRAM_FW}}{{PROGRAM.ITEM}}` |

系統會按程序的實際次序，逐項挑對應的那一列來用，最後把你做的兩列範本
都刪掉。

⚠️ 第二列要**真的**在 Word 裡把三格合併成一格並設成置中——系統只複製你
做好的那一列，不會幫你合併儲存格。

### 第 5 步：處理不是每週都有的內容

例如詩班頌唱不是每週都有。在那一列任何位置加：

```
{{#IF:CHOIR_TITLE}}
```

詩班曲名是空的時候，整列會被刪掉。

段落（不在表格內，例如文字方塊裡的獻花）用 `{{#IFP:}}`：

```
{{#IFP:FLOWER_THIS_WEEK}}本週獻花：{{FLOWER_THIS_WEEK}}
```

### 第 6 步：上載到雲端硬碟，取得檔案 ID

1. 把範本 `.docx` 上載到 Google 雲端硬碟
2. 開啟它，看網址：

```
https://drive.google.com/file/d/【這一段就是檔案 ID】/view
```

3. 把那一段貼進 `Config` 工作表對應的設定鍵（見上面「需要做幾多個範本」）

### 第 7 步：撳「檢查範本佔位符」

選單「週報系統 ▸ 檢查範本佔位符」。

這一步**唯讀**，不會改任何東西，但會把結果寫進 `Diagnostics` 工作表，
列出：

- 範本用到的全部佔位符
- **⚠️ 範本用到、但系統不提供** ← 多數是打錯字
- 系統提供、但範本沒有用到 ← 確認是不是故意的
- **⚠️ 疑似被切斷的佔位符** ← 見「常見錯誤 1」

**兩項 ⚠️ 都要清空才算做好。**

### 第 8 步：試產生一次

1. 把 `Config` 的 `TEMPLATE_MISSING_VALUE_MODE` 暫時改成 `KEEP`
2. 選單「產生本週週報（Word）」，輸入一個有資料的主日日期
3. 開啟產生出來的檔案，**逐頁對比印刷版**：
   - 有沒有佔位符原樣留在紙上？（那些就是打錯字的）
   - 版面有沒有走位？
   - 表格的列數對不對？
4. 全部正確之後，把 `TEMPLATE_MISSING_VALUE_MODE` 改回 `BLANK`

## 常見錯誤

### 1. ⚠️ 佔位符被 Word 拼寫檢查切斷（最常見）

**現象**：範本上明明打住 `{{SERMON_TITLE}}`，印出來卻原樣是
`{{SERMON_TITLE}}`。同一份範本其他佔位符都正常，只有某幾個不行。

**原因**：Word 為了做拼寫檢查、記住語言標記，會把一段字在內部切成好幾
截。`{{SERMON_TITLE}}` 可能被存成 `{{` ＋ `SERMON` ＋ `_TITLE}}` 三截，
系統找不到完整的那一串。

系統會盡量自動把切開的接回去（大部分情況都成功），但如果中間夾了書籤、
註解，或者兩截的字型真的不同，就接不到。

**怎樣知道中招了**：撳「檢查範本佔位符」，看「疑似被切斷的佔位符」那一項。

**修法**：把那個佔位符**整段選取 → 刪掉 → 一口氣重新打一次**。打完再檢查
一次。

💡 打之前先在那個位置按一下，確認游標在同一個格式範圍內；不要由別處
複製貼上半截過來。

### 2. 用了全形括號

`｛｛SERMON_TITLE｝｝` 認不到，一定要半形 `{{` `}}`。

💡 中文輸入法很容易打出全形括號。打佔位符之前先切回英文輸入法。

### 3. 大小寫不符

`{{Sermon_Title}}`、`{{sermon_title}}` 都認不到。**全部大寫**，字之間用
底線。

### 4. 清單表格留了多過一列

`{{#EACH:}}` 那個表格**只可以留一列**（程序表例外，留兩列）。多出來的列
不會被複製，會原樣印出來。

### 5. 忘記在第一格加 `{{#EACH:}}`

只寫 `{{ANNOUNCEMENT.TEXT}}` 而沒有 `{{#EACH:ANNOUNCEMENT}}`，系統不知道
那一列要複製，那一格會變成空白。

### 6. 改了格式

不要改任何格式。系統只換字，範本的版面是什麼樣，印出來就是什麼樣——
改壞了不會有任何錯誤訊息，要印出來才發現。

### 7. 佔位符名稱自己發明

只有 [佔位符對照表.md](佔位符對照表.md) 列出的名稱有效。自己發明的名稱
（例如 `{{講題}}`）系統認不到，會照 `TEMPLATE_MISSING_VALUE_MODE` 的設定
變成空白或原樣保留。

## 日後改範本

改範本**不需要動任何程式**：

1. 在雲端硬碟直接編輯那個 `.docx`（或者上載新版覆蓋）
2. 撳「檢查範本佔位符」確認沒有問題
3. 產生一次試試

⚠️ 如果換了一個**新檔案**（不是覆蓋舊檔），記得把 `Config` 內的檔案 ID
更新成新的。

---

## 想加一個新的佔位符

如果週報上有一格會逐週改變、但 [佔位符對照表.md](佔位符對照表.md) 沒有
對應的佔位符，那需要改程式（在 `src/BulletinRender.gs` 加），請告知
開發者。

不要自己在範本發明一個名稱——系統認不到，只會變成空白。
