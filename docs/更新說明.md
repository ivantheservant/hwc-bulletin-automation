# 更新說明（CHANGELOG）

版本號＝部署日期 `yyyy.MM.dd`（同一日第二次部署加 `-2`）。程式內的版本在 `src/Constants.gs` 的 `APP_VERSION`，
試算表選單「關於本系統」、填寫介面頁底、「設定差異檢查」報告都會顯示。**每次改版，最上面加一段同一個版本號**
（`tests/version.test.js` 核對兩邊一致）。每段寫：改了甚麼、部署之後要做甚麼（例如「初始化工作表」）、有沒有新 Config 鍵。

給其他堂會或其他教會的維護者：先看自己的版本號（「關於本系統」），再由那一個版本之後的各段逐段看。

## 2026.11.03-6

- **提速**：
  - 內容表的修改時間改用 Drive API 只取修改時間（以前開整個檔案物件）。
  - 「上一季連續到」：填寫介面平常載入時，上一季內容表的修改時間與上次一樣、十分鐘之內，就用記下的結果，不打開上一季內容表
    （同職事表快取的做法）。「重新載入（讀最新）」、選單匯入、觸發器照舊每次打開。
- **分段用時更細**：資料模型拆成本週職事表、下週職事表、週報行與覆寫、程序表、事奉框、其餘；另外列出讀了幾次週報工作表、最慢的三張。
- **Word 範本**（另交檔案，管理員用「管理版本 ▸ 上載新版本」上載）：下週事奉每一行加「段落不分欄」，一項排不下就整項移到下一欄。
- 部署之後：不用按「初始化工作表」；沒有新 Config 鍵。

## 2026.11.03-5

- **程序表的「聖餐」跟職事表**（職事表那邊核對 09-27）：新條件 `IF_DUTY:<PostID>|<後備條件>`。職事表「聖餐襄禮」這一週有人→印聖餐；
  職事表講明「不設」→不印；未排定→按後備條件（每月第一個主日）。新建的工作表四個範本用 `IF_DUTY:COMMUNION|WEEK_IN:1`
  （浸禮合堂 `IF_DUTY:COMMUNION|ALWAYS`）。
- **載入分段用時更細**：「伺服器用時」按一下，看得到讀職事表用了多久（打開職事表或快取）、內容表每一步（打開檔案、讀分頁、上一季連續到、比較）。
- 部署之後：**ProgramTemplates 四行「聖餐」的「出現條件」要改**（初始化工作表不會改已有的行）：TPL_NORMAL、TPL_ANNIVERSARY、TPL_COMBINED
  改為 `IF_DUTY:COMMUNION|WEEK_IN:1`；TPL_COMBINED_BAPTISM 改為 `IF_DUTY:COMMUNION|ALWAYS`。不改亦照舊可用（照舊按第一個主日）。
  沒有新 Config 鍵。

## 2026.11.03-4

- **名字後面帶括號備註**（例如翻譯「張元紅（粵／華）、方浩天（粵／英）」）：稱呼加在名字後、括號之前，印「張元紅姊妹（粵／華） 方浩天弟兄（粵／英）」（跟以往週報）。
  括號前的名字對不上人名稱呼表的，照原文印。
- 部署之後：不用按「初始化工作表」；沒有新 Config 鍵（如果上一版之後未按過，按一次）。

## 2026.11.03-3

## 2026.11.03-2

- **載入再快一些**：同一次載入之內同一張工作表只讀一次；開頁的工作表結構檢查減少讀取次數。
- **職事表快取**：只用於開頁、換週、背景匯入（觸發器、產生 Word、發佈、寄出一律直接讀職事表）。
  職事表檔案的修改時間與上次一樣、而且存了未超過十分鐘才用；否則照舊讀職事表。快取放在週報試算表一張隱藏工作表 `_職事表快取`，
  可以隨時刪除（下一次載入自動重建）。職事表一格都不寫。
- **新按鈕「重新載入（讀最新）」**（頂部）：職事表、內容表一律讀最新內容，不用任何快取。「重新讀取職事表（不覆寫）」亦一律讀最新。
- 頂部「伺服器用時」可以按，訊息列顯示分段用時。
- 部署之後：不用按「初始化工作表」；沒有新 Config 鍵。

## 2026.11.03

- **內容表「崇拜人數」改回一個崇拜日期一行**（與家事報告、代禱事項一致；合堂崇拜／祈禱會／兒童三格是「有效」之前的三欄）。
  2026-10-30 至 11-03 建的日子橫放內容表照常匯入（只出提示），按「更新本季內容表…」先預覽、確定之後改回（舊分頁改名隱藏保留）。
- **載入速度**：開頁只叫一次伺服器（主日清單、發佈狀態、預設主日）；內容表匯入改在畫面顯示之後於背景做，完成之前鎖住所有按鈕並顯示「仍在載入」；
  內容表（連上一季）沒有改過就不打開（記錄三十分鐘有效）；內容表版面狀態、Word 範本事奉格數按檔案修改時間記住；頂部顯示伺服器用時（滑鼠停留看分段）。
- **「連續到」帶入的家事報告、代禱事項在填寫介面顯示來源**（由哪一日起、連續到哪一日、本季或上一季的內容表）。
  Announcements／Prayers 最後加兩欄（內容表主日日期、內容表連續到）。
- **多堂會（甲、同一份程式碼、多個部署）**：Config `CONGREGATION_NAME`（預設「粵語堂」）；電郵範本可用 `{{CongregationName}}`；
  檔名樣式可用 `{{CONGREGATION}}`；`deploy_multi.bat`＋`deploy-targets.txt` 一次部署到多個堂會；選單「設定差異檢查（唯讀）」。
  步驟與設定清單見 `docs/多堂會部署.md`。
- 部署之後：**按「初始化工作表」**（新 Config 鍵 `CONGREGATION_NAME`；Announcements、Prayers 各加兩欄）。
  未按之前讀 Announcements／Prayers 會報「第 2 行機器鍵與程式定義不符」。
