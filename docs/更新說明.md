# 更新說明（CHANGELOG）

版本號＝部署日期 `yyyy.MM.dd`（同一日第二次部署加 `-2`）。程式內的版本在 `src/Constants.gs` 的 `APP_VERSION`，
試算表選單「關於本系統」、填寫介面頁底、「設定差異檢查」報告都會顯示。**每次改版，最上面加一段同一個版本號**
（`tests/version.test.js` 核對兩邊一致）。每段寫：改了甚麼、部署之後要做甚麼（例如「初始化工作表」）、有沒有新 Config 鍵。

給其他堂會或其他教會的維護者：先看自己的版本號（「關於本系統」），再由那一個版本之後的各段逐段看。

## 2026.11.04-1

- **電郵範本**（Ivan 11-03 註解）：
  - 稱呼按收件組別（Config 新鍵 `RECIPIENT_GROUP_TITLES`，預設 `CC=堂委,DB=執事,ADMIN=幹事,WORSHIP=敬拜同工,IT=`）：「各位堂委、執事：」；
    沒有對應稱呼就寫「各位同工：」。新佔位符 `{{Salutation}}`。
  - 標題與內文不再寫「基督教中國佈道會奧克蘭聖道堂」，改用堂會名稱（`{{CongregationName}}`）。
  - 標題加版本號：草稿預覽 `v1`、`v2`…（同一主日每寄一次加一）；已發佈用發佈版本。新佔位符 `{{VersionNo}}`、`{{VersionLabel}}`。
  - 「季度內容表邀請」由職事表系統寄出，週報系統不再寄（Config 新鍵 `CONTENT_SHEET_INVITE_EMAIL_ENABLED`，預設 FALSE）。
  - 「職事表分歧提醒」電郵預設停用，只在填寫介面提示（Config 新鍵 `CONFLICT_NOTICE_EMAIL_ENABLED`，預設 FALSE）。
  - 「初始化工作表」會把**沒有人改過**的系統範本（標題、內文與舊預設完全相同）換成新版本，逐格記 AuditLog；人手改過的不動。
- **提示改為人話**（Ivan 測試結果 C）：填寫介面的警告與錯誤訊息不再提工作表名稱、PersonID、Config 鍵、試算表選單；
  原本的技術內容收在「給管理員參考」（按一下展開），有需要時可以抄給管理員。產生 Word 時多出來的警告亦併入頂部「警告」清單。
- **特別崇拜可以有自己的家事報告等**（Ivan 測試結果 C）：建立時「家事報告等」選〔另外填寫（在內容表選這一日）〕，或者之後在那一期頂部
  按〔改為另外填寫…〕。家事報告、代禱事項、團契、財政報告改為讀這一日自己的：內容表那四張分頁的「主日」下拉加入這一日，
  自動匯入、〔重新匯入（只限這一個主日）〕、重設照常處理；「連續到」包括這一日的行亦會出現。上週崇拜人數仍然跟上一個主日；
  讀經經文等三欄仍然在填寫介面填。預設照舊跟上一個主日，不用再改上一個主日的內容表。按〔改回跟上一個主日…〕可以改回。
  BulletinWeeks 最後加一欄 `SPECIAL_CONTENT_SOURCE`。
- 部署之後：**要按「初始化工作表」**（三個新 Config 鍵；BulletinWeeks 加一欄；電郵範本換新版本）。
